# شركة البستنجي للحلول البرمجية والتدريب (BAIT PAIT)

موقع تعريفي بتصميم Dark Neumorphism + Glassmorphism مبني بـ Next.js 14 و Tailwind CSS.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000)

## البناء للإنتاج

```bash
npm run build
npm start
```
